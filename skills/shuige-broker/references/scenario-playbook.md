# 经纪人带教：多场景学习地图

本手册用于咨询、话术、复盘和演练。每张场景卡的“合成示例”都不是聊天记录原文；示例只是展示决策结构，不可把其中条件当成岗位事实。

## 先定位沟通阶段

1. **初识**：说明身份/联系原因，了解一个优先条件。
2. **需求澄清**：把会员已说的条件复述准确，只补问影响筛选的缺口。
3. **岗位评估**：依据当前资料逐项说岗位、工资、班次、地点、食宿、费用与要求；未知就核实。
4. **决策与安排**：尊重比较/犹豫，或确认面试、到厂、体检、报到等明确事项。
5. **变化与跟进**：处理未回复、临时变更、拒绝、到场后问题；给一次适当下一步，不施压。
6. **需要升级**：工资争议、收费、合同、劳动关系、工伤、歧视、健康要求、投诉等，整理事实并交由负责人/正式流程核实。

## 场景卡

### A. 第一次联系

- **目标**：让对方知道谁在联系、为什么联系，并自然打开需求沟通。
- **先问**：当前最看重哪一项条件；不要一次盘问完整档案。
- **合成示例**：`你好，我是这边帮你了解工作的经纪人。想先问问你现在找工作最看重哪一点？我了解后再按你的情况帮你看看。`
- **注意**：样本对话可能缺少会话开头，不要宣称有唯一的水哥开场话术。

### B. 对方只给出一个偏好

- **目标**：确认偏好，然后补一个决定筛选方向的问题。
- **例：长白班**：`好，长白班我记下了。你想找哪个区域的工作？我按这个方向帮你看看，岗位和具体条件确认后再告诉你。`
- **下一步**：有岗位资料后再确认班次定义、具体时间、地点、收入、食宿和要求。
- **避免**：说“有很多长白班”“给你安排好了”，除非当前信息确实核实。

### C. 需求含糊或多项条件冲突

- **目标**：区分必须条件、可商量条件和未知项。
- **问法**：`你刚才提到白班和离住处近都比较重要。如果先选一个最不能让步的条件，你更看重哪项？`
- **下一步**：得到优先顺序后，再核对实际岗位；若两项暂时无法兼顾，说明真实取舍，不替会员作决定。

### D. 工资/收入咨询

- **已核实**：按资料讲工资组成、计薪方式、发薪周期和浮动条件，并说明适用岗位。
- **待核实**：`你问的工资我先帮你核实清楚，包含工资构成和可能浮动的部分。确认准确后我再跟你说，先不随便报一个数。`
- **必须核实**：底薪、计件/绩效、加班计算、扣款、试用期、发薪日和实际口径。收费或欠薪争议升级处理。
- **避免**：只报最高月收入、把“综合收入”当保底，或承诺一定拿到某金额。

### E. 班次、工时与休息

- **目标**：把口语偏好翻译成可核实的安排。
- **需确认**：固定白班还是轮班、具体上下班时段、休息天数、加班是否自愿/安排、班次是否会变。
- **问法**：`你希望固定白班，还是能接受偶尔轮班？我先把这个条件记清楚。`
- **避免**：把历史岗位的班次当成当前空缺条件。

### F. 地点与通勤

- **目标**：确认区域、可接受通勤范围和交通限制，不索取不必要的精确住址。
- **问法**：`你主要考虑哪个区域？通勤大概多远你能接受？`
- **下一步**：核实岗位地址、交通方式、集合点和班次与交通的可行性。
- **隐私**：除非流程确有需要，不要求具体门牌、实时位置或身份证件。

### G. 住宿、餐食或生活条件顾虑

- **目标**：先听清楚是哪一点不合适，再核实当前安排。
- **合成示例**：`住宿这块我先了解一下你觉得不合适的地方，是环境、人数还是其他安排？我再帮你跟现场确认清楚，有确定的情况后再回复你。`
- **核实**：宿舍位置/人数/费用、水电、餐食与岗位资料分别确认；如无可选方案，直接说明。
- **避免**：用另一个历史案例保证“肯定能换”或淡化安全/卫生问题。

### H. 介绍岗位与匹配说明

- **顺序**：工作内容 → 已核实工资结构 → 班次工时 → 地点/交通 → 食宿/费用 → 任职要求 → 仍待核实项。
- **表达**：只讲与会员当前优先条件有关的信息；如有不利条件，和优点一起讲清楚。
- **检查**：每一项能否指向当前可用资料？若不能，将它标成待确认而不是补全猜测。

### I. 犹豫、比较或提出异议

- **流程**：承认顾虑 → 澄清具体原因 → 回应已知事实 → 核实未知 → 提供可选下一步。
- **问法**：`明白，你现在主要担心的是工作时间，还是收入不稳定？我先把最影响你决定的那点确认清楚。`
- **避免**：争辩、制造稀缺感、反复重复优点，或把对方的犹豫解释为“不想工作”。

### J. 面试/到厂安排

- **核对清单**：日期与时段、准确地址/集合点、联系人/对接方式、需携带材料、交通预留和临时变更联系人。
- **确认句**：`我把时间和地址再跟你确认一遍：你计划在___到___。如果安排有变化，先联系___。`
- **规则**：填空只能来自当前确认信息；缺一项就先问内部负责人，不凭记忆编造。

### K. 迟到、未到或临时改期

- **目标**：先确认人是否安全、是否仍计划前往，再处理新时间。
- **问法**：`我看到原定时间已经过了，想确认你现在还方便过去吗？如果需要改时间，我们先重新跟现场确认。`
- **避免**：未经核实把岗位名额、企业态度或处分后果说成事实。

### L. 没回复/暂缓/明确拒绝

- **没回复**：参考实际约定的回复时间，发送一条简短低压力跟进；不连续轰炸。
- **暂缓合成示例**：`好的，你先考虑。有需要时再找我，我这边不催你。`
- **明确拒绝**：尊重决定，停止推进；只有对方主动提出新需求时再继续。
- **避免**：通过家属、其他账号或非授权渠道反复联系。

### M. 入职、报到与到岗后支持

- **报到前**：再次确认已核实的时间、地点、联系人和材料；不要把面试通过等同于已录用/已到岗。
- **到岗后问题**：收集会员陈述、具体时间和可核实材料，区分事实/转述/猜测，转交对应负责人。
- **避免**：未经证据就承诺工资、劳动关系、住宿整改或赔偿结果。

### N. 高风险与需转交场景

- **工资拖欠、收费纠纷、合同、劳动关系、工伤、安全、骚扰、歧视、健康/年龄/性别限制、证件或个人数据请求**：先表示会认真处理，记录必要的非敏感事实，依正式渠道转交。
- **推荐表达**：`这个情况我先按你说的内容记录下来，具体处理办法我需要找负责同事/正式流程核实，确认后再回复你。`
- **禁止**：法律结论、报复性建议、隐瞒安全风险、基于受保护特征筛人或决定谁能获得工作机会。

### O. 图片、语音、定位等多模态内容

- 先确认材料表达了什么，不从无法读取的图片/语音猜测岗位或会员意图。
- 若当前工具看不到附件，请用户去标识化后描述关键事实或提供可读转写；不要要求会员身份证、完整住址等不必要信息。
- 复盘时注明哪些判断来自文字，哪些依赖未提供的附件，哪些仍未知。

## 复盘量表：只评当前这一段

每项可标“做到 / 部分做到 / 还没有 / 材料不足”，不计算成经纪人总分：

1. 是否先回应会员刚说的需求/顾虑？
2. 是否识别沟通阶段，并只问了一个关键缺口？
3. 已核实事实与未知内容是否分开？
4. 是否讲清具体、可执行的下一步？
5. 是否避免过度承诺、施压、泄露隐私和敏感属性决策？
6. 材料是否缺少语音、图片、前文或岗位资料，以至于无法判断？

训练反馈最多指出一两个最有帮助的改动，并给一版合成改写。不要根据单段对话推断会员去留或话术效果。
